                ▼
    ┌────────────────────────┐
    │  Backend API Route     │
    │  Parse request         │
    └────────────────────────┘
                │
                │ Split: ["...", "---", "..."]
                ▼
    ┌────────────────────────┐
    │  For each letter:      │
    │  1. Get morse pattern  │
    │  2. Build regex        │
    │  3. Thompson's NFA     │
    │  4. Subset → DFA       │
    │  5. Traverse DFA       │
    └────────────────────────┘
                │
                │ Return JSON:
                │ { decoded: "SOS",
                │   letters: [{morse: "...", letter: "S", ...}, ...],
                │   steps: [...] }
                ▼
    ┌────────────────────────┐
    │  Frontend receives     │
    │  1. Store data         │
    │  2. Render graph (D3)  │
    │  3. Show output        │
    │  4. Enable animation   │
    └────────────────────────┘
                │
                ▼
    ┌────────────────────────┐
    │  User sees:            │
    │  • Graph visualization │
    │  • Output: SOS         │

    │  • Interactive controls│

═══════════════════════════════════════════════════════════════════════════
                        ALGORITHM FLOW (Letter "A" = ".-")
═══════════════════════════════════════════════════════════════════════════

Input: Morse pattern ".-"
    │
    ▼
┌───────────────────────────────┐
│  1. REGEX PARSING             │
│  Pattern: ".-"                │
│  AST: Concat(Symbol('.'),     │
│             Symbol('-'))      │
└───────────────────────────────┘
    │
    ▼
┌───────────────────────────────┐
│  2. THOMPSON'S CONSTRUCTION   │
│                               │
│  NFA:                         │
│  q0 --[.]-> q1 --[-]-> q2     │
│                        (final)│
│                               │
│  with epsilon transitions     │
└───────────────────────────────┘
    │
    ▼
┌───────────────────────────────┐
│  3. SUBSET CONSTRUCTION       │
│                               │
│  DFA:                         │
│  d0 --[.]-> d1 --[-]-> d2     │
│                        (final)│
│                               │
│  No epsilon transitions       │
└───────────────────────────────┘
    │
    ▼
┌───────────────────────────────┐
│  4. DFA TRAVERSAL             │
│                               │
│  Input: ".-"                  │
│  Step 1: d0 --'.'-> d1        │
│  Step 2: d1 --'-'-> d2        │
│  d2 is final → ACCEPT         │
│  Output: 'A'                  │
└───────────────────────────────┘
    │
    ▼
┌───────────────────────────────┐
│  5. VISUALIZATION             │
│  Render graph with D3.js      │
│  Animate transitions          │
│  Show step log                │
└───────────────────────────────┘
